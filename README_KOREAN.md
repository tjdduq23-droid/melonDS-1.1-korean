# melonDS 1.1 한국어 메뉴 패치 (비공식)

이 소스는 melonDS 1.1을 기반으로 메인 창의 메뉴 항목과 일부 화면 배치 선택지를 한국어로 바꾼 작업본입니다.

## 번역 범위
- 파일 / 시스템 / 보기 / 설정 / 도움말 메뉴
- 해당 메뉴의 주요 명령과 화면 배치 선택지
- 설정 대화상자 내부의 모든 항목까지 번역한 완전 한글화는 아닙니다.

## Windows x64 자동 빌드
`.github/workflows/build-windows.yml`이 `main` 또는 `master` 브랜치에 push되면 GitHub Actions에서 Windows 빌드를 시도합니다. 저장소의 **Actions** 탭에서 실행 결과를 확인하고, 성공한 실행의 **Artifacts**에서 `melonDS-1.1-korean-windows-x64`를 내려받으세요.

수동 실행은 Actions에서 Windows 워크플로를 선택한 뒤 **Run workflow**를 누르면 됩니다.

## 주의
- 이 작업본은 Windows에서 컴파일 및 실행 검증을 완료하지 않았습니다.
- 빌드 성공 여부는 GitHub Actions 결과로 확인해야 합니다.
- melonDS 원본 프로젝트의 라이선스 및 고지 사항은 원본 파일을 따릅니다.
